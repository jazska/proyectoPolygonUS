flowchart TD

A[Inicio: Usuario abre el asistente] --> B[Saludo y presentación del agente]
B --> C[Consulta de propósito: "¿Qué tipo de canción quieres crear?"]
C --> D{El usuario responde}
D -->|Inspiradora / Personal| E[Asistente genera borrador lírico con LLM]
D -->|Romántica / Triste / Energética| F[Asistente genera letras adaptadas al tono emocional]

E --> G[El usuario revisa y pide cambios]
F --> G
G --> H{¿Deseas agregar música o ritmo?}
H -->|Sí| I[Llamada a API MusicGen o Suno.ai para generar melodía]
H -->|No| J[Asistente ofrece guardar solo la letra]

I --> K[Asistente combina letra + audio y sugiere estructura de canción]
J --> K
K --> L{¿Deseas un video o visualización?}
L -->|Sí| M[Llamada a API de Kapwing o Pika.art para generar videoclip]
L -->|No| N[Asistente finaliza el proyecto]

M --> O[Integración de letra + música + video]
N --> O

O --> P[Llamada a modelo Hugging Face (p. ej., emotion-detector)]
P --> Q[Análisis de coherencia emocional y recomendaciones]

Q --> R{¿Usuario desea mejorar la letra?}
R -->|Sí| S[Regresa al módulo de generación lírica con feedback del análisis]
R -->|No| T[Asistente ofrece exportar el proyecto y compartir]

T --> U[Fin del flujo: descarga o publicación sugerida]
